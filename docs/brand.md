# WritSet brand

WritSet makes context engineering for coding agents easier to understand and track.
The identity pairs the Cursor W icon with a plain, single-color WritSet title.

## Assets

| Asset | Use |
| --- | --- |
| [Cursor W](assets/writset-icon.svg) | Cobalt icon for light backgrounds |
| [Cursor W, dark surface](assets/writset-icon-dark.svg) | Light blue icon for dark backgrounds |
| [Cursor W, inverse](assets/writset-icon-inverse.svg) | White icon for cobalt backgrounds |
| [Light logo](assets/writset-logo-light.svg) | Icon and dark title on a light background |
| [Dark logo](assets/writset-logo-dark.svg) | Icon and light title on a dark background |

The icon combines a bracket-shaped W with a terminal cursor. Use the approved
geometry as supplied. Keep the icon separate from the title; do not recolor parts
of the word, stretch the mark, or add letter spacing.

## Typography

Use **Space Grotesk** for headings, the title, and body copy. Use **JetBrains Mono**
for code and small technical labels. The logo title uses Space Grotesk at weight
500 with its natural spacing. SVG text is outlined so GitHub renders it without
requiring visitors to install a font.

The [Space Grotesk license](assets/fonts/space-grotesk-LICENSE.txt) and original
[font source](assets/fonts/space-grotesk.woff2) accompany the editable SVG assets.

## Colors

| Color | Value | Role |
| --- | --- | --- |
| Cobalt | `#2455CC` | Primary accent and light-background icon |
| Light blue | `#88B4FF` | Dark-background icon and active details |
| Ink | `#101B30` | Light-background title and text |
| Night | `#080E1C` | Dark page background |
| Paper | `#F4F7FC` | Dark-background title and light surfaces |
| Muted | `#96A4BF` | Secondary text on dark surfaces |

The product name is **WritSet**. Use **WritSet** for the GitHub repository and
public-facing prose. Use lowercase `@intelip/writset` for the npm package and
`writset-*` for commands. Legacy `tabellio-*` commands, schemas, Git refs, and stored
records remain compatible during the transition. Historical
Tabellio assets and release records are retained as history, not current branding.
